## Why

Users navigate entity lists but lack a central contract workspace and a clear next action. Connect existing authorized workflows into a coherent platform without changing financial calculations.

## What Changes

- Organize navigation as Trabalho, Financeiro, Cadastros and Administração; use Visão geral and Recebimentos consistently for the corresponding surfaces while keeping existing URLs.
- Add a full contract workspace with overview, finance, team, attachments and history navigation, preserving quick drawers and list context.
- Retain optional overdue work preview code, hidden by default after product review; expose contextual receipt actions and preserve filter context.
- Explain stored remuneration amounts and manual adjustments without claiming settlement or reconstructing historical percentages.
- Standardize invalid-submit focus, form sections, and dependent selection feedback.
- Add settings with actual account/theme controls, current office context and workflow guidance.

## Capabilities

### New Capabilities
- `platform-workflows`: Connected contract workspace, task entry points, contextual navigation, financial explanations and settings.

### Modified Capabilities
None. Existing financial rules and permissions remain authoritative; presentation changes are specified in the new capability.

## Non-goals

Billing, tenant provisioning, invitations/permission administration, spreadsheet import, a new payout ledger, custom report builder and persistent firm-setting writes. No disabled or pretend controls for these future capabilities.

## Impact

All authenticated roles see only currently granted capabilities. Existing firm and resource scopes apply to every new entry point. Changes affect navigation, shared forms, dashboard, contracts, fees and remunerations. No migration or new dependency.
